設置槓桿
> **交易产品覆盖范围：现货/USDT永续/反向合约**

### HTTP 請求
POST `/cloud/trade/v3/position/set-leverage`

### 請求參數
| 參數 | 是否必需 | 類型 | 說明|
|:----- |:-------|:-----|------ |
|[category](../enum#category) |**true** |string |产品类型：`spot`，`linear`，`inverse` |
|symbol |**true** |string |合約名稱|
|buyLeverage |**true** |string |<ul><li>單倉:<code>buyLeverage</code> 必須等於 <code>sellLeverage</code></li><li>雙倉:<ul><li>逐倉保證金: <code>buyLeverage</code> 可以與 <code>sellLeverage</code> 不相等</li><li>全倉保證金: <code>buyLeverage</code> 必須等於 <code>sellLeverage</code></li></ul></li></ul> |
|sellLeverage |**true** |string |[`1`, [風險限額](../market/risk-limit#)允許的最大槓桿數]. _注意：單倉模式下，`buyLeverage`需要和`sellLeverage`保持一致_|

---

### 響應參數
無

### 請求示例

```shell
POST /cloud/trade/v3/position/set-leverage HTTP/1.1
Host: openapi-testnet.zoomex.com
X-BAPI-SIGN: XXXXX
X-BAPI-API-KEY: XXXXX
X-BAPI-TIMESTAMP: 1672281605082
X-BAPI-RECV-WINDOW: 5000
Content-Type: application/json

{
    "category": "linear",
    "symbol": "BTCUSDT",
    "buyLeverage": "6",
    "sellLeverage": "6"

}
```
