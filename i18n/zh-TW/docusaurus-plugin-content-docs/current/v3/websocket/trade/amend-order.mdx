`op` = `order.amend`。連接、鑒權和信封見 [Websocket 下單指南](guideline)。`args` 裡有且只有一個訂單對象。業務規則與 [修改委託單](../../order/amend-order) 相同。

> **交易產品覆蓋範圍：現貨 / USDT 永續 / 反向合約**

:::info important
您只能修改**未成交**或**部分成交**的訂單。
:::

### Websocket
`order.amend`，主網 `wss://stream.zoomex.com/v5/trade`，測試網 `wss://stream-testnet.zoomex.com/v5/trade`

### 請求參數
以下字段放在 `args` 的唯一對象裡。

| 參數 | 是否必需 | 類型 | 說明|
|:----- |:-------|:-----|------ |
|[category](../../enum#category) |**true** |string |產品類型：`spot`，`linear`，`inverse` |
|symbol |**true** |string |合約名稱 |
|orderId |false |string |訂單 Id。`orderId` 和 `orderLinkId` 必傳其中一個 |
|orderLinkId |false |string |用戶自定義訂單 Id。`orderId` 和 `orderLinkId` 必傳其中一個 |
|orderIv |false |string |隱含波動率 |
|triggerPrice |false |string |期貨為條件單觸發價。現貨為止盈止損觸發價 |
|qty |false |string |修改後的訂單數量。若不修改，請不要傳該字段 |
|price |false |string |修改後的訂單價格。若不修改，請不要傳該字段 |
|tpslMode |false |string |`Full`：全部倉位止盈止損。`Partial`：部分倉位止盈止損。僅對 `linear` 和 `inverse` 有效 |
|takeProfit |false |string |修改後的止盈價格。傳 `"0"` 表示取消訂單上的止盈。若不修改，請不要傳該字段 |
|stopLoss |false |string |修改後的止損價格。傳 `"0"` 表示取消訂單上的止損。若不修改，請不要傳該字段 |
|[tpTriggerBy](../../enum#triggerby) |false |string |止盈價格觸發類型。若下單時未設置，修改止盈時該字段必傳 |
|[slTriggerBy](../../enum#triggerby) |false |string |止損價格觸發類型。若下單時未設置，修改止損時該字段必傳 |
|[triggerBy](../../enum#triggerby) |false |string |觸發價格類型。僅對 linear 和 inverse 有效 |
|tpLimitPrice |false |string |觸發止盈後的限價。僅當原訂單是部分止盈止損限價單時有效 |
|slLimitPrice |false |string |觸發止損後的限價。僅當原訂單是部分止盈止損限價單時有效 |

### 響應參數
字段在 `data` 裡，不在 REST 的 `result` 裡。

| 參數 | 類型 | 說明|
|:----- |:-----|----- |
|orderId |string |訂單 Id |
|orderLinkId |string |用戶自定義訂單 Id |

業務校驗失敗時，`retCode` 和 `retMsg` 與 REST [修改委託單](../../order/amend-order) 一致。

### 請求示例

```json
{
    "reqId": "amend-001",
    "header": {
        "X-BAPI-TIMESTAMP": "1672217108106",
        "X-BAPI-RECV-WINDOW": "5000"
    },
    "op": "order.amend",
    "args": [
        {
            "category": "linear",
            "symbol": "ETHUSDT",
            "orderLinkId": "linear-004",
            "triggerPrice": "1145",
            "qty": "0.15",
            "price": "1050",
            "takeProfit": "0",
            "stopLoss": "0"
        }
    ]
}
```

### 響應示例

```json
{
    "reqId": "amend-001",
    "retCode": 0,
    "retMsg": "OK",
    "op": "order.amend",
    "data": {
        "orderId": "c6f055d9-7f21-4079-913d-e6523a9cfffa",
        "orderLinkId": "linear-004"
    },
    "retExtInfo": {},
    "connId": "cnt5leec0hvan15eukcg-2v"
}
```
