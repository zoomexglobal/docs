`op` = `order.amend`. The connection, authentication and envelope are in the [Websocket Trade Guideline](guideline). `args` contains exactly one order object. Business rules match [Amend Order](../../order/amend-order).

> **Trading products covered: Spot / Linear / Inverse**

:::info important
You can only modify **unfilled** or **partially filled** orders.
:::

### Websocket
`order.amend` on `wss://stream.zoomex.com/v5/trade` (testnet: `wss://stream-testnet.zoomex.com/v5/trade`)

### Request Parameters
These fields are the single object in `args`.

| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|[category](../../enum#category) |**true** |string |Product type: `spot`, `linear`, `inverse` |
|symbol |**true** |string |Symbol name|
|orderId |false |string |Order ID. Either `orderId` or `orderLinkId` is required |
|orderLinkId |false |string |User customised order ID. Either `orderId` or `orderLinkId` is required |
|orderIv |false |string |Implied volatility |
|triggerPrice |false |string |<ul><li>For futures, the conditional order trigger price</li><li>For spot, the TP/SL trigger price</li></ul>|
|qty |false |string |Order quantity after modification. Do not pass it if not modify the qty|
|price |false |string |Order price after modification. Do not pass it if not modify the price|
|tpslMode |false |string |TP/SL mode <ul><li>`Full`: entire position for TP/SL. Then, tpOrderType or slOrderType must be `Market`</li><li>`Partial`: partial position tp/sl</li></ul>Valid for `linear` and `inverse`|
|takeProfit |false |string |Take profit price after modification. If pass "0", it means cancel the existing take profit of the order. Do not pass it if you do not want to modify the take profit |
|stopLoss |false |string |Stop loss price after modification. If pass "0", it means cancel the existing stop loss of the order. Do not pass it if you do not want to modify the stop loss |
|[tpTriggerBy](../../enum#triggerby) |false |string |The price type to trigger take profit. When set a take profit, this param is **required** if no initial value for the order|
|[slTriggerBy](../../enum#triggerby) |false |string |The price type to trigger stop loss. When set a stop loss, this param is **required** if no initial value for the order|
|[triggerBy](../../enum#triggerby) |false |string |Trigger price type. Only valid for linear and inverse|
|tpLimitPrice |false |string |Limit order price when take profit is triggered. Only working when original order sets partial limit tp/sl|
|slLimitPrice |false |string |Limit order price when stop loss is triggered. Only working when original order sets partial limit tp/sl|

### Response Parameters
Returned inside `data`, not REST `result`.

| Parameter | Type | Comments|
|:----- |:-----|----- |
|orderId |string |Order ID |
|orderLinkId |string |User customised order ID |

If business validation fails, `retCode` and `retMsg` match the REST [Amend Order](../../order/amend-order) response.

### Request Example

```json
{
    "reqId": "amend-001",
    "header": {
        "X-BAPI-TIMESTAMP": "1672217108106",
        "X-BAPI-RECV-WINDOW": "5000"
    },
    "op": "order.amend",
    "args": [
        {
            "category": "linear",
            "symbol": "ETHUSDT",
            "orderLinkId": "linear-004",
            "triggerPrice": "1145",
            "qty": "0.15",
            "price": "1050",
            "takeProfit": "0",
            "stopLoss": "0"
        }
    ]
}
```

### Response Example

```json
{
    "reqId": "amend-001",
    "retCode": 0,
    "retMsg": "OK",
    "op": "order.amend",
    "data": {
        "orderId": "c6f055d9-7f21-4079-913d-e6523a9cfffa",
        "orderLinkId": "linear-004"
    },
    "retExtInfo": {},
    "connId": "cnt5leec0hvan15eukcg-2v"
}
```
