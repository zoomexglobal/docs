`op` = `order.cancel`. The connection, authentication and envelope are in the [Websocket Trade Guideline](guideline). `args` contains exactly one order object. Business rules match [Cancel Order](../../order/cancel-order).

> **Trading products covered: Spot / Linear / Inverse**

:::info important
- You must specify `orderId` or `orderLinkId` to cancel the order.
- If `orderId` and `orderLinkId` do not match, the system will process `orderId` first.
- You can only cancel **unfilled** or **partially filled** orders.
:::

Cancel all orders is not available on this connection. Use REST [Cancel All Orders](../../order/cancel-all).

### Websocket
`order.cancel` on `wss://stream.zoomex.com/v5/trade` (testnet: `wss://stream-testnet.zoomex.com/v5/trade`)

### Request Parameters
These fields are the single object in `args`.

| Parameter | Required | Type | Comments|
|:----- |:-------|:-----|------ |
|[category](../../enum#category) |**true** |string |Product type: `spot`, `linear`, `inverse` |
|symbol |**true** |string |Symbol name|
|orderId |false |string |Order ID. Either `orderId` or `orderLinkId` is **required** |
|orderLinkId |false |string |User customised order ID. Either `orderId` or `orderLinkId` is **required** |
|orderFilter |false |string |Valid for `spot` **only**. `Order`, `tpslOrder`. If not passed, `Order` by default|

### Response Parameters
Returned inside `data`, not REST `result`.

| Parameter | Type | Comments|
|:----- |:-----|----- |
|orderId |string |Order ID |
|orderLinkId |string |User customised order ID |

If business validation fails, `retCode` and `retMsg` match the REST [Cancel Order](../../order/cancel-order) response.

### Request Example

```json
{
    "reqId": "cancel-001",
    "header": {
        "X-BAPI-TIMESTAMP": "1672217376681",
        "X-BAPI-RECV-WINDOW": "5000"
    },
    "op": "order.cancel",
    "args": [
        {
            "category": "linear",
            "symbol": "BTCUSDT",
            "orderId": "c6f055d9-7f21-4079-913d-e6523a9cfffa"
        }
    ]
}
```

### Response Example

```json
{
    "reqId": "cancel-001",
    "retCode": 0,
    "retMsg": "OK",
    "op": "order.cancel",
    "data": {
        "orderId": "c6f055d9-7f21-4079-913d-e6523a9cfffa",
        "orderLinkId": "linear-004"
    },
    "retExtInfo": {},
    "connId": "cnt5leec0hvan15eukcg-2v"
}
```
